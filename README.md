## 🎯 Project Description

This project is a **Multi-Vendor E-Commerce Platform** designed specifically for handmade artisans such as resin artists, candle makers, and craft designers.

It allows:

* Vendors to list and manage products
* Customers to browse and purchase items
* Admin to control and monitor the platform

The system bridges the gap between traditional artisans and digital marketplaces.

---

## 🚀 Key Features

* 🔐 User Authentication (JWT-based)
* 🛍️ Product Listing & Management
* 🛒 Cart & Wishlist Functionality
* 📦 Order Tracking
* 📊 Admin Dashboard
* 👥 Role-Based Access Control
